# [[serial experiments]] SimEstab

SimEstab is an engine for establishment simulations: worlds you build up from nothing and
then keep running. A game is one thing it can become. It could also be an environment for
reinforcement learning, or a world model. And it could be the world for what we call a
Prospection Model: one model, policy or agent that acts in a complex environment by
looking ahead at the outcome of each decision before it makes it.

The way it is made is an experiment. Our team doesn't write the code. We prompt LLM coding
agents, and they write the design docs, the code and the tests. When the agents miss
something, we step in and fill the gap by hand. The question is simple: can a project like
this be built that way?

The experiment is still running, and the engine is early. Some parts work today; most of
what an establishment simulation needs is still ahead. The goal is an engine that works.
Everything else is a side effect.
